Reactベースの柔軟な設計

Reactコンポーネントで画面を構築。描画にはCanvas 2D APIを採用し、特別な実行環境を選ばず軽快に動作します

マルチプラットフォーム

様々なデバイスで動作します。

desktop app : Windows / macOS / Linux

※たぶん Steam 配布できます。

browser : Google Chrome / Safari / Microsoft Edge / Firefox

※HTML5 + JSが動作するなら大概いけます。
